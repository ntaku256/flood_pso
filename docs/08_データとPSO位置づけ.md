本リポジトリは性質の異なる 2 系統からなる。混同しないこと。

- **(A) PSO 洪水校正（研究本体）**: 観測浸水域を再現する `(water_level, Δh マップ)` を最適化する逆問題。
- **(B) 歩行可能ワールド可視化（Phase 8）**: 御坊の街を Minecraft 構造（NBT/litematic）で再現。建物・道路・橋・浸水を描く。

PSO が探索するのは地形でなく **水位パラメータ**。(B) は (A) の結果（浸水域）を世界に重ねるだけで、精細地形・建物・橋は別データから作る。

## 3. PSO の使い方と意義

### 問題（逆問題＝洪水校正）
観測浸水域を再現するパラメータを求める。
- **探索変数**: 全体水位 `water_global ∈ [3,8]m` ＋ 空間補正 **Δh(x,y)** を K×K ブロック化 `∈[-2,2]m`（bilinear で全画面展開）→ **D = 1 + K²（17 / 65 / 257）**
- **フォワードモデル** (`simulate_flood`): **バスタブ＋連結成分**（平滑化DEM < water かつ河川に連結＝浸水、深さ=water−DEM）。1評価 ~ms と安価 → 数千評価が可能
- **目的関数**: 浸水深 MAE 最小（IoU 補助）。**非微分・閾値ベース・多峰**
- **手法**: 標準PSO(pyswarms) vs **CCPSO2**（協調共進化：次元を部分群に分割し context vector で順次最適化、`|pbest−gbest|` スケールの Cauchy/Gauss サンプリング、停滞時 Random Grouping、速度概念なし）。グループサイズは **適応的**（Li & Yao 2012 準拠。候補集合 s∈{2,5,10,25,50,100,250} から改善停滞時に選び直す）

### 研究仮説と結果
「**高次元 LSGO では分割統治(CCPSO2)が標準PSOを上回る**」を実問題で検証（3シード平均）。

| D = 1+K² | 標準PSO loss | CCPSO2 loss | 勝者 |
|---|---|---|---|
| 17 (K=4) | **0.0007** | 0.0155 | PSO（分割オーバーヘッドが無駄） |
| 65 (K=8) | **0.0135** | 0.0967 | PSO |
| 257 (K=16) | 0.1629 | **0.0987（−39%, IoU+1.9pt, ばらつきも小 std0.0133<0.0422）** | **CCPSO2** |

卒研での位置づけ: 本来の応用（経路最適化→来年度 IA）の代理として、御坊・日高川の洪水校正という連続高次元問題で CCPSO2 の高次元優位を再現。Li & Yao (2012) の LSGO 知見と整合。

> 注: 旧実装は固定グループサイズ s=16 で CCPSO2 を不当に弱めていた（実装上の落とし穴）。適応グループサイズへ修正後、K=16 の CCPSO2 loss は 0.1148 → 0.0987 に改善（主張 −29% → −39%）。低次元 K=4/8 は依然 PSO が勝ち、高次元 D=257 で逆転する構図は維持・強化。
> 正則化なしの素のベンチでは CCPSO2 の Δh パラメータ復元(Δh_RMSE)は PSO より悪い（過適合）が、平滑化正則化 λ≈0.02 で PSO 同等(≈0.73)になり IoU 優位は全 seed で保たれる（`docs/LayerB_Δh逆問題とPP-PSO論文_整理.md` §6）。標準 LSGO ベンチでも適応CCPSO2 は 5関数×D=100/500/1000 の全15ケースで標準PSO に勝利（同 md §6.3）。

### 既知の限界
- **Δh は ill-posed**: 浸水境界しか拘束せず内陸 Δh は同定不可。loss が低くても真値復元は不完全（「正直な不確実性表現」）。
- フォワードがバスタブ（非 hydrodynamic）。

## 4. 他手段との比較・妥当性（率直な評価）

問題の性質＝**ブラックボックス・非微分・箱制約・D≤257・フォワードが安価・多峰/ill-posed**。

### 妥当な点
- 非微分ブラックボックスに **derivative-free メタヒューリスティクス(PSO/CCPSO2) は自然**。
- フォワードが安価 → **Bayesian最適化(GP)の標本効率は不要**、かつ GP は D>50 で破綻（D=257 は範囲外）→ 不適。
- 勾配/随伴法は微分可能ソルバが要る → バスタブ+連結成分は非微分で**不自然**。
- 結果（D=257で CCPSO2 勝ち）は LSGO 文献と整合し、**研究ベンチとして筋が通る**。

### 弱い点・要補強
1. **ベースラインが弱い**: 「分割統治が効く」を主張するなら **CMA-ES（連続 D~数百で実質SOTA）が真の比較相手**。標準PSO だけでは「PSO に分割が効く」しか言えない。→ **sep-CMA-ES / DECC-G / MLCC を baseline に追加**すると主張が強固。
2. **実用(洪水校正)としては非標準**: 観測同化が定石（**EnKF / 4D-Var**：観測誤差・事前分布・不確実性を扱える）。応用論文なら「同化が標準だが本研究は高次元最適化器の比較が主目的」と明記。
3. **ill-posed は定式化の問題**: per-cell Δh(257) は過剰。**物理基底（河床勾配・河川距離関数）で低次元化**すれば well-posed 化＆D削減でき、どの手法でも改善。
4. **フォワードがバスタブ**: 実氾濫は浅水方程式。校正の物理妥当性は限定的（ベンチの清潔さとのトレードオフ）。

### 結論
**研究ベンチ目的としては妥当で良い構成**。主張を固めるには **①CMA-ES＋他CC手法を baseline 追加、②ill-posed を物理基底で緩和** が効く。実用校正ではデータ同化が標準である旨を一文添えると守りが堅い。
