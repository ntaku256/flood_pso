# 03 高次元化設計

> 2026-04-28

## 動機

`02_ベースライン再現.md` で確認したとおり、現状の2変数（`water_level`, `sigma`）問題は IoU≈0.99 で容易に解け、**CCPSO2 を持ち出す研究的動機が薄い**。問題そのものを高次元化して、標準PSO が苦戦する／CCPSO2 の分割統治が効くケースを構築する。

## 設計方針

### 1. 空間分布する水位補正 Δh(x,y)

物理的なアナロジー：実河川の氾濫では、上下流で水面勾配が存在し、また周辺地形・建物・土地利用で局所的な水位差が生じる。これをブロック単位の補正 `Δh_k` で表現する：

```
water_level_field(x, y) = water_level_global + Δh(x, y)
```

`Δh` は K×K のブロックマップとして保持し、DEM 全画面（H×W）にバイリニア補間でアップサンプルする（タイル境界の段差を防ぐため）。

### 2. 探索次元

| K | 補正マップ次元 | + global | 合計 D |
|---|---|---|---|
| 4 | 16 | +1 | **17** |
| 8 | 64 | +1 | **65** |
| 16 | 256 | +1 | **257** |

- D=17：標準PSOで何とかなるはず
- D=65：標準PSO はぐらつき始める領域
- D=257：CCPSO2 の分割統治が明確に効くはず

### 3. 探索範囲

- `water_level_global ∈ [3.0, 8.0]` [m]
- `Δh_k ∈ [-2.0, +2.0]` [m]（ブロックごと、独立）

### 4. 参照マスクの再設計（合成 ground truth）

現状の `dem ≤ 5m` という参照は「`water_level=5` に固定すれば即解ける」自明な問題なので使えない。

**合成 ground truth を導入：**

1. 真の `water_level_true` と真の `Δh_true(K×K)` を事前に固定（hand-tuned あるいは固定シードの乱数）
2. これを使って `simulate_flood_hd` で「正解」浸水マスクを生成
3. PSO はこの正解マスクとの IoU を最大化することで、`(water_level_true, Δh_true)` を回復する

ground truth は探索空間内に必ず存在するので、原理的には IoU=1.0 が達成可能。これにより「PSOが真値にどこまで近づけるか」を清潔に評価できる。

### 5. 評価指標

- **IoU (mask)**：従来通りの浸水域一致度
- **‖Δh_est − Δh_true‖**：パラメータ空間でのRMSE
- **収束履歴**：イテレーション vs best_cost
- **計算時間**：標準PSO vs CCPSO2
