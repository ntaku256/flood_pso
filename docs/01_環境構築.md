# 01 環境構築（Linux / WSL2）

> 2026-04-28

## 目的
オリジナルの `flood_pso/` は Windows パスを直書きしており、`main.py:32` の `DATA_ROOT` が `C:\Users\moriken\…` を参照していた。Linux 環境（WSL2）で再現実行できるよう整備する。

## 手順

### 1. Python 仮想環境
```bash
cd /home/moriken/web-app/flood_pso
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

PEP 668 によりシステム Python への直接インストールは不可。`venv` を作って `requirements.txt` をインストール。

### 2. パスの修正

`src/main.py`:
- `DATA_ROOT = Path(r"C:\Users\moriken\…")` を削除
- 環境変数 `FLOOD_PSO_DEM_DIR` があればそれを使用、なければ `../kennkyuu20260114/地形データ/FG-GML-503561-DEM5A-20250620` を既定とする

`src/dem_parser.py` (`__main__` 部):
- 同様に Linux で動く既定パスへ変更

### 3. Git LFS でDEM XMLを取得
`kennkyuu20260114/.gitattributes` で `*.xml` は LFS 管理。WSL に `git-lfs` 未導入だったため：

```bash
# sudo 不要のユーザーローカル導入
curl -sL https://github.com/git-lfs/git-lfs/releases/download/v3.5.1/git-lfs-linux-amd64-v3.5.1.tar.gz | tar -xzC /tmp
mkdir -p ~/.local/bin
cp /tmp/git-lfs-3.5.1/git-lfs ~/.local/bin/
export PATH="$HOME/.local/bin:$PATH"

cd /home/moriken/web-app/kennkyuu20260114
git lfs install --local
git lfs pull --include "地形データ/FG-GML-503561-DEM5A-20250620/*.xml"
```

### 4. 動作確認
```

```

DEM 5m メッシュ 94 タイルのモザイクが成立。御坊市周辺、緯度 33.83〜33.92, 経度 135.13〜135.25。
