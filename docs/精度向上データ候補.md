# 御坊歩行ワールド／洪水シミュ ― 精度・リアリティ向上に使えるデータ源（2026-06 調査）

現状（[[docs/08]] の使用データ: LiDAR・FG-GML・OSM橋・空中写真・5m DEM・GTハザード）を踏まえ、
**よりリアル／より高精度**にするために追加で使えそうなデータを目的別に整理。

**凡例**
- 状態: ✅利用中 ／ ◎入手済or容易・未使用 ／ △条件付き・要確認 ／ ❌御坊未対応
- 効果: 🏙リアリティ ／ 🌊洪水精度 ／ 🚶避難ナビ

## 9. 研究の妥当性向上（データでなく比較対象・手法）
- **CMA-ES / DECC-G / MLCC** を baseline に追加 → 「CCPSO2 が高次元で優れる」主張を強化（[[docs/08]] 課題①）。
- per-cell Δh の **ill-posed 緩和**: 物理基底（河床勾配・河川距離関数）で低次元化。
- 実用洪水校正の定石 **データ同化(EnKF/4D-Var)** との位置づけを明記。
