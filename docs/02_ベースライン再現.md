## 評価と限界

- **IoU 0.99 はほぼ自明**：参照マスクが `dem ≤ 5.0m` という閾値で生成されており、`water_level ≈ 5.0m` を見つければそのまま一致する。PSO の難しさを示す問題設定にはなっていない。
- **2次元では CCPSO2 を持ち出す動機が薄い**：CCPSO2 は高次元 (`D≫10`) で真価を発揮する手法。現状のままでは「分割統治」「Random Grouping」が冗長な装飾にしかならない。
- **現実の校正問題としては素朴**：全領域均一の `water_level` と `sigma` しか持たないため、上下流での水位勾配・地表粗度の空間的不均一性を表現できない。

## ⇒ Phase 1 への接続

問題設定を以下のように拡張する（詳細：`03_高次元化設計.md`）：

1. DEM を K×K のブロックに分割
2. 各ブロックで独立な「水位補正 Δh」または「sigma_local」を保持
3. ブロック数 K² が探索次元（K=4で16次元、K=8で64次元、K=16で256次元）
4. 参照マスクは「全域一律閾値」ではなく、より物理的根拠のあるもの（ハザードマップ画像など）に差し替え可能とする

これで CCPSO2 の有効性を比較する研究的意義が生まれる。
